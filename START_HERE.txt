📋 QUICK START:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Install Tesseract OCR (Required for image upload)
  macOS:     brew install tesseract
  Verify:    tesseract --version

STEP 2: Run the application
  Option A - Easy way:
    cd sudoku-solver
    ./run.sh

  Option B - Manual way:
    cd sudoku-solver
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    python app.py

STEP 3: Open in browser
  http://localhost:5000

🎮 HOW TO USE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
METHOD 1: Upload Image
  1. Click "Upload Image" or drag & drop
  2. Wait for OCR processing
  3. Review extracted grid
  4. Choose solve method

METHOD 2: Manual Entry
  1. Click on cells to enter numbers
  2. Use arrow keys to navigate
  3. Or click "Load Sample" for example
  4. Choose solve method

🔧 TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Port 5000 in use?
  → Edit app.py and change port to 5001

OCR not working?
  → Check Tesseract: tesseract --version
  → Install: brew install tesseract

Import errors?
  → Activate venv: source venv/bin/activate
  → Reinstall: pip install -r requirements.txt
